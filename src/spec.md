# Specification

## Summary
**Goal:** Make the background music reliably audible and update the post-NO prompt escalation sequence in English while keeping NO always selectable.

**Planned changes:**
- Fix music playback so Play/Pause reliably starts audible audio after a user click/tap, with clear UI messaging when autoplay is blocked.
- Ensure the volume slider changes the actual playback volume and the Play/Pause UI accurately reflects the playing state.
- Update the NO-click escalation to display the provided sequence as a prominent flashing/pulsing English prompt message near/above the buttons (not as the NO button label).
- Continue increasing the YES button size on each NO click while keeping the NO button visible and clickable at all times and continuing to record NO selections.

**User-visible outcome:** Users can start and hear the background music with working play/pause and volume controls (and see instructions if autoplay is blocked), and after each NO click they see an animated English escalation prompt while still always being able to click NO.
